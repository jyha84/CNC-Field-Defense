# C&C Field Defense — Jungle Outpost v0.2 — Woodland UI

실제 Combined Arms 유닛/지형을 사용하는 C&C 스타일 타워디펜스 플레이 프로토타입입니다.

## 바로 실행

`web/index.html` 또는 별도로 제공한 `CA_Field_Defense.html`을 브라우저에서 여세요.
이미지·한글 폰트·게임 코드가 포함된 단일 HTML이며 서버나 인터넷 연결이 필요하지 않습니다.
모바일 파일 미리보기가 스크립트를 실행하지 않으면 파일을 다운로드한 뒤 브라우저에서 열어 주세요.

1. 우측 생산창에서 유닛을 선택합니다.
2. 흙길 주변 잔디의 밝은 점을 누르면 배치됩니다.
3. `1차 웨이브 시작`을 누르면 자동으로 조준·공격합니다.
4. 배치한 유닛을 눌러 강화하거나 철수할 수 있습니다.

## 포함 기능

- C&C 스타일 금속 패널, 생산창, 레이더, 크레딧·전력 표시.
- 패널 뒤에 흐릿하고 어두운 우드랜드 위장무늬 적용. 무늬만 부드럽게 처리하고 글자와 아이콘은 선명하게 유지.
- 실제 스프라이트와 Jungle 잔디·흙길·나무·바위.
- 편성 가능 10종: 소총병, 수류탄병, 로켓 보병, 험비, 배틀 탱크, 다연장 로켓, 매머드 탱크, 가드 타워, 고급 가드 타워, 오벨리스크.
- 32종 도감. 아직 플레이에 포함하지 않은 유닛은 확장 후보로 표시.
- 보병 이동/공격 애니메이션, 전차 차체와 포탑 분리 표시.
- 12차 웨이브, 보병·차량·중장갑·공중 적, 마지막 지휘 전차.
- 공중 적도 지상 적과 같은 굽은 경로를 따라 이동합니다. 공중 표적 판정과 대공 유닛 제한은 유지합니다.
- 처치 보상, 웨이브 보급, Lv.3까지 강화, 투자금 70% 철수 환급.
- 단계별 유닛 해금, 발전소 증설, 사령부 수리.
- 사거리·격자 표시, 2배속, 일시정지, 음향 켜기/끄기, 승리·패배·재시작.
- 마우스 및 터치. 세로는 아래 생산창, 가로는 우측 생산창. 화면이 낮으면 생산창 내부를 스크롤합니다.
- 다른 앱/탭으로 전환하면 자동 일시정지. 복귀 후 계속하기를 누르세요.

기본 수비대 2기와 $1500으로 시작합니다. 4차부터 공습이 있으므로 로켓 보병 등 대공 유닛을 준비하세요. 기본 지급 유닛은 구매 투자금이 없으므로 철수 시 기본 환급액이 0입니다.

단축키는 전장을 클릭한 뒤 사용합니다: Space 일시정지/다음 웨이브, G 격자, Esc 배치 취소.
현재 진행 저장 기능은 없으며 새로고침하면 초기화됩니다.

## 개발 이어가기

- `web/engine.js`: DOM과 독립된 게임 규칙, 밸런스, 경로·표적·피해·웨이브.
- `web/app.js`: Canvas 렌더링, 마우스/터치, 생산 UI, 레이더, 합성 효과음.
- `web/template.html`: C&C 스타일 UI와 반응형 레이아웃.
- `assets.json`: 실제 그래픽과 지형, 경로/장애물, 도감 정보.
- `web/field-ui.woff`: 필요한 문자만 포함한 Noto 한글 글꼴.
- `build.py`: 위 데이터를 단일 HTML로 묶습니다. Python 3로 `python build.py` 실행.
- `tests/engine.cjs`: 핵심 전투 규칙과 12차 클리어 시뮬레이션.
- `tests/browser.cjs`: 실제 Chromium에서 UI·모바일 터치 검증. 실행 환경에 맞춰 `CHROMIUM_EXECUTABLE` 지정.
- `tests/preview.cjs`: 실제 자원으로 전투를 진행한 미리보기 캡처용.
- `make_assets.py`: 이전 `ca-atlas` 작업 폴더가 형제 디렉터리에 있을 때 원본에서 다시 추출하는 보조 도구. 일반 수정·빌드에는 필요하지 않습니다.

원본 데이터 리비전: b67e287461c4e1086a3ba46d8c0dcb1bb4dd6748
출처: https://github.com/Inq8/CAmod
원본 문서와 글꼴 라이선스는 `upstream-notices/`, 추출 정보는 `provenance.json`에 있습니다.

리마스터 HD가 아닌 클래식 픽셀 그래픽이며 모드 변형도 포함됩니다. 적은 원본 팀 색상 범위에 대응하는 색을 붉게 바꿨습니다. 흙길은 실제 도로 타일 일부를 이어 붙였습니다. 전투 수치·UI·탄환/폭발/레이저 효과·합성 사운드는 이번 타워디펜스용입니다. 원작 엔진의 모든 조명·팔레트·포탑 오프셋을 동일하게 재현한 것은 아닙니다.

## 안드로이드 프로젝트

`android/`에는 이 HTML을 로드하는 WebView 앱 소스가 포함되어 있습니다. 이번 전달물에는 설치용 APK가 없습니다.
이 환경에는 Android SDK가 없어 APK 빌드와 실제 안드로이드 기기 검증은 수행하지 않았습니다.

로컬 Android Studio에서 android 폴더를 열거나, JDK 17 / Android SDK Platform 35 환경에서 `android/build-apk.ps1`을 실행할 수 있도록 기존 빌드 스크립트를 포함했습니다. 빌드 시 web/index.html을 앱 assets로 복사합니다. 빌드 환경의 의존성 다운로드가 필요합니다.

## 확인한 범위

실제 Chromium: 로딩, 금지 위치 배치 차단, 유닛 배치, 강화, 철수, 웨이브 개시, 자동 전투, 일시정지, 도감 32종, 도움말, 모바일 터치, 세로/가로 가로넘침 검사. 콘솔 JavaScript 오류 없음.
Node 시뮬레이션: 지출/환급, 잠금/전력 제한, 패배, 12차 승리, 대공 표적 제한. 현재 밸런스에서 정상 보상·구매·강화·수리만으로 12차 클리어(사령부 18/20)를 확인했습니다. 모든 전략이 승리한다는 의미는 아닙니다.
